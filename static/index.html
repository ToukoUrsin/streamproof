MADE TO BE QUESTIONED

Observation, then interpretation.

01

A person selects the water

Manually choose a rectangle. Image detail, exposure, bright reflections and selected area are checked with OpenCV.

02

Compare only when the views match

Stable bank features align repeat photographs. Matching regions are compared for color and texture; lighting changes can make the result inconclusive.

03

Let evidence change the next action

Retake a blurry image, match the earlier angle, or request a closer/upstream view. Every branch is visible in the trace.

04

A person records the conclusion

No diagnosis, pollution attribution, or water-safety claim. Heuristic thresholds need real field calibration before operational use.
